Product-only hanger and invisible-mannequin shots qualify; closeups are excluded. Reference preparation is measured separately and excluded from cutter timing.

The pre-existing annotations are read only after prediction. Semantic pass uses the existing precision/recall ≥ 0.60 rule and its detached-structure exception.
