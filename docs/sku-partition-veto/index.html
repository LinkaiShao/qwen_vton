What this does

The whole SKU is inspected twice, reversing image and region order and renaming every region ID using frozen Qwen/Qwen3-VL-32B-Instruct. Every region is available to the model. A kept identity must have visible support in every image under both inspections. Extra and disputed fragments are checked against the confirmed garment in the full source photograph. Matching compares visible garment pieces, not the title or the item for sale. Repeated styling is eligible too.

No segmentation model is trained here. Kept and removed masks contain only whole original SAM3 partitions. A mixed or defective input partition cannot be repaired by this veto. There is no forced survivor and no calibrated confidence claim.
