What was changed and tested

The old readout averages six normalized native target→reference attention maps. The layer-agreement candidate takes their geometric mean, reducing the effect of a peak supported by only one or two layers. It is the same rule for every source point, image and timestep. No left/right coordinate prior or forced point separation is used.

The coordinate-field candidate separately tests a LeFFA-style attention-derived flow: reference-conditional attention at temperature 2 yields the expected source coordinates for each target location, then the field is inverted by nearest source coordinate. It has clear failures here. This conditional, temperature-scaled field is an auxiliary readout, distinct from the original full-key attention probabilities.

The actual full-key softmax is preserved for the old and layer-agreement candidates. The readout copies Q/K before V, then selects target-query/reference-key attention. It never changes the attention used to render the image.

All 20 steps are inspected independently; no earlier/later maps are used to produce a point. Full denoising is used here to obtain a final image for evaluation. This does not yet prove localization during arbitrary noisy training inputs.

This is exploratory development on one known failure plus five additional garments with existing verified masks. No independent exact point-transfer ground truth exists for these six examples, so no pixel-accuracy percentage is claimed. A source location can be hidden or have no visible counterpart. Both candidates still force an argmax even then; neither has a validated visibility detector.
