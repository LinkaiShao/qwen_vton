What changed

  • One complete SAM3 four-concept export per image; no cross-export border remnants.
  • 12 queries with the original eight protected from new-query self-attention interference; extra outputs introduced over 500 updates.
  • Confidence-weighted, area-bounded matched mask loss; global same/different-garment relations.
  • Training-only queries pool C-RADIO features under SAM3 masks; intermediate stages receive mask supervision. These are adaptations, not SAM3 decoder-query or intermediate-logit distillation.
  • Easy regions retained when the starting model agrees with SAM3; shared feature layers initially frozen, then tuned at lower learning rate.

The quality estimator is trained against teacher mask overlap, not human truth. Exclusivity and foreground coverage are guaranteed by decoding; correctness of the boundaries must still pass evaluation. No RGB-only smoothing merges similarly textured garments.
